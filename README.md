# english

アメリカ英語の reading・listening・speaking を、学習記録と間隔復習を引き継いで練習するリポジトリです。

## 使い方

GitHubを接続した会話で、次のように依頼します。

> @GitHub Rih0z/english のAGENTS.mdと最新の循環プロンプトを読み、今日の英語学習を始めて。終了したら今日のフォルダへ記録をプッシュして。

講師は最新記録を読み、同日なら続き、別日なら期限到来の復習から実際の練習を始めます。「学習をお願い」だけでも、このリポジトリが会話内で特定されていれば同じ運用です。終了・中断時に結果を保存します。GitHubへの接続・読み書き権限が必要です。これはAIへの運用指示であり、GitHub単独で授業を実行する自動化ではありません。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| [AGENTS.md](AGENTS.md) | 学習開始・日付判定・GitHub保存のルール |
| [latest.json](latest.json) | 最新学習日の循環JSONとノートへの参照 |
| [first-prompt.json](first-prompt.json) | 学習実績がない初回専用。現行循環JSONと同じ指導ルール |
| `YYYY/MM/DD/english_learning_cycle.json` | その時点までの状態・履歴を持つ循環JSONの正本 |
| `YYYY/MM/DD/english_daily_note_YYYY-MM-DD.md` | その学習日の読みやすい振り返り |

現在の学習記録は [2026-11-12のJSON](2026/11/12/english_learning_cycle.json) と [日次ノート](2026/11/12/english_daily_note_2026-11-12.md) です。以後はlatest.jsonを起点にしてください。

## 日付と継続

- タイムゾーンは **America/Los_Angeles**。開始時に当日を確認し、保存先を `YYYY/MM/DD/` にします。
- 同日中は同じLesson・同じ2ファイルへセッションを追記します。同日の復習テストは繰り返しません。
- 別日は前日のノートを確定し、Lessonを1つ進め、期限到来項目を最大5件復習してから練習します。過去の記録を引き継ぎます。
- 深夜をまたぐ続行や過去分の統合は明示された実施日に保存します。過去分の追記でlatest.jsonを古い日へ戻しません。
- 継続時にfirst-prompt.jsonで履歴を初期化しません。初回のみ空の状態からLesson 1を開始します。

## 学習と保存

主技能と終了条件は講師が履歴から選びます。writingは対象外です。練習は英語、求められた説明と日次振り返りは日本語。読み・聞き取りの理解と英語表現を別々に扱い、未実施の成績は作りません。

各セッションの終了・中断時に、循環JSON全体・日次ノート全体・latest.jsonを同じコミットでmainへ反映します。保存後は内容を再取得して検証し、リンクを返します。通常の記録保存はその都度の確認なしで実施します。接続や保存に失敗した場合は未保存と伝え、更新内容を返します。

## 旧配置について

`2026/11/11*.json` と対応ノートは旧スキーマの履歴です。`2026/12/12a.*` は内部の学習日が **2026-11-12** で、配置の日付と一致していません。元ファイルは履歴として残し、内容を正しい `2026/11/12/` へ引き継ぎました。最新の選択には内部学習日とlatest.jsonを使用します。

指導ルールを変更する際は、現行循環JSON・first-prompt.json・AGENTS.md・README.mdを揃えます。schema 2.1では、初回テンプレートも最新循環プロンプトの指導手順に統一しています。
