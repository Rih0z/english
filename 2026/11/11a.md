## 文法・意味の整理

- **a challenge**：challengeを単数の数えられる名詞として使うため、ここではaが必要です。
- **Unfamiliar names are challenging for me\.** も自然です。challengingは形容詞なので、その直前にaは付けません。
- **will start this Friday** と **starts this Friday** はどちらも文脈に合う表現です。原文との差を文法ミスと混同しません。
- **The light show starts Friday\.** も自然です。thisの追加は、今回の目標文をそのまま再現するための練習です。
- **want**＝欲しい・したい。I want a beer\. / I want to go\.
- **won’t**＝will not。I won’t go\.
- **tell … apart** のtellは「区別する」という使い方です。「聞く」のlistenと同じ意味ではありません。
- wantとwon’tは両方とも語末にtがあり、tだけを区別の手掛かりにはできません。聞き分けができるかは今回未測定です。
